## Learning Java

## Estrutura

- 'logica/' - conceitos básicos de lógica de programação usando Java
- 'fundamentos/' - conceitos básicos da linguagem com aprofundamentos
- 'estruturas_controle/' - condicionais e estruturas de repetição
- 'metodos/' - criação e utilização de métodos
- 'arrays/' - arrays e estruturas de dados básicas
- 'orientacao_objetos/' - conceitos de orientação a objetos
- 'exercicios/' - exercícios práticos
- 'projetos/' - pequenos projetos desenvolvidos durante os estudos
- 'integradores/' - projetos de grande escala
